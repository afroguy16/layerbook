# Auto Book Home

**Auto Book** is a simple workshop tool that helps mechanics log the work on every car, so each car gets a family doctor. Booking comes later, built on that record.

**Stage:** DRAFTIDEA · **Owner:** Tega · **Last updated:** 

## Current decisions

| Topic | Where it stands |

| Who pays | The mechanic, per completed booking, from prepaid credit. Logging is always free. [Brief](https://ewvie.atlassian.net/wiki/spaces/AB/pages/62750721/Idea+brief+Auto+Book+family+doctor+for+your+car#How-it-makes-money) |
