# Design overview (start here)

*Context: index of Auto Book's design research (16 Oct 2026). Read in this order; each page explains its own method and sources.*

## The goal

A mechanic logs a car, and an owner books, in **about one minute on a phone in Lagos** (low data, mixed literacy, WhatsApp-native). See the [Idea brief](https://ewvie.atlassian.net/wiki/spaces/AB/pages/62750721/Idea+brief+Auto+Book+family+doctor+for+your+car).

1. [UX research & design playbook](https://ewvie.atlassian.net/wiki/spaces/AB/pages/64028673/UX+research+design+playbook+how+we+ll+work): the methods we use and how we measure (task time, taps/fields, SUS).
2. [Booking UI research: selection methodology & shortlist](https://ewvie.atlassian.net/wiki/spaces/AB/pages/64094209/Booking+UI+research+selection+methodology+shortlist): where we looked, scoring rubric, top 10, rejected list.

## Top 5 principles in one glance

1. The system types, the user taps.
2. Live inside WhatsApp and links (no app, no login for owners).
3. Three urgency colours plus words: Fix now / Fix soon / Can wait.
4. One thing per screen, plain words.
5. Light by default (tiny first load, no maps/photos unless asked).
